⚙️ 02 Setup & Installation
📱 Select Your Device

Fire TV 4K — Fire OS 7 based on Android 9. Fully supports sideloading via Downloader. Navigate to Settings → My Fire TV → Developer Options.

✅ Setup Checklist
0 of 5 complete
  • Enable Developer Options in Settings → My Fire TV → Developer Options
  • Turn on ADB Debugging (required for sideloading on some devices)
  • Enable Apps from Unknown Sources (Settings → My Fire TV → Developer Options → Apps from Unknown Sources)
  • Install Downloader from Amazon Appstore — search "Downloader by AFTVnews"
  • Open Downloader and allow storage permission — grant file access when prompted
🛠️ Step-by-Step Instructions
  1. On your Fire TV remote, press and hold the Home button → select Settings
  2. Navigate to My Fire TV → Developer Options
  3. Toggle ADB Debugging to ON
  4. Toggle Apps from Unknown Sources to ON — confirm the warning
  5. Press Home → go to Find → Search → type Downloader
  6. Select Downloader by AFTVnews → Download and Install
  7. Open Downloader → tap Allow for storage permission
  8. You're ready! Enter a URL or shortcode in the address bar to download APKs

    🔧 07 Troubleshoot
    🩺 Common Issues & Solutions
    ❌ "Unknown Sources" option is missing or greyed out ▼

    This is common on newer Fire OS versions. Navigate to Settings → My Fire TV → Developer Options. If Developer Options is hidden, go to Settings → My Fire TV → About and click the Fire TV serial number 7 times rapidly to unlock Developer Options. Then enable "Apps from Unknown Sources" specifically for the Downloader app.

    ⚠️ Downloader app says "Install Blocked" ▼

    Starting with Fire OS 7, you must allow unknown sources per-app. Go to Settings → Privacy → Apps from Unknown Sources. Find Downloader in the list and toggle it to ON. If the toggle is missing, you may need to fully close and reopen Downloader first, then try installing the APK again.

    🌐 Downloads fail with "Connection Error" ▼

    Ensure your Fire TV is connected to the internet. Try opening the Silk browser and visiting a website to confirm connectivity. If Wi-Fi is connected but downloads fail, try: (1) restarting your router, (2) forgetting and reconnecting to Wi-Fi, (3) switching DNS to 8.8.8.8 in your router settings, (4) checking if the APK URL is still valid and accessible from a browser.

    📦 APK installs but app won't open / shows as incompatible ▼

    The APK you downloaded may be built for a different CPU architecture. Fire TV devices use ARM64-v8a processors. Ensure you're downloading the correct ARM version of the APK. Also verify the app requires Android 5.0+ (Fire OS 5 = Android 5.1, Fire OS 7 = Android 9). Some apps require Google Play Services which is not available on Fire OS.

    💾 Downloader is stuck or frozen during download ▼

    If the download bar is not moving for more than 60 seconds: (1) Press the Back button to cancel, (2) Check your internet connection speed, (3) Try the download again — some servers throttle connections, (4) Clear the Downloader app cache via Settings → Applications → Manage Installed Applications → Downloader → Clear Cache, (5) Try an alternative download mirror URL if one is available.

    🔄 Sideloaded app disappeared after reboot ▼

    Amazon Fire OS may automatically uninstall apps from unknown sources after system updates or factory resets. This is a known behavior. To prevent this: (1) Do not apply system updates until you've backed up your APKs, (2) Enable Do Not Automatically Install Updates in developer options, (3) Keep the original APK files so you can quickly reinstall. Consider using AFTVnews developer tools for persistent sideloading.

    💥 App crashes immediately after opening ▼

    If a sideloaded app crashes on launch: (1) Go to Settings → Applications → Manage Installed Applications, find the app, tap Clear Cache then Clear Data, (2) Ensure sufficient free storage — at least 500MB recommended, (3) Try uninstalling and reinstalling from a fresh APK download, (4) Check if the app requires specific permissions you haven't granted — go to App Settings → Permissions, (5) Some apps crash if Google Play Services is unavailable; look for a Fire TV-specific build.

    🐢 Download speed is very slow ▼

    Slow download speeds can be caused by multiple factors: (1) Wi-Fi signal strength — move your router closer or use a Wi-Fi extender; Fire TV 4K supports 802.11ac (Wi-Fi 5), (2) Ethernet — use a USB-to-Ethernet adapter for wired speeds, (3) VPN — if a VPN is active, disconnect it as it routes traffic through a remote server adding latency, (4) CDN issues — the APK host may have slow download servers; try an alternative mirror, (5) ISP throttling — try downloading at different times of day.

    🔢 Shortcode not found or expired ▼

    Downloader shortcodes are not permanent and can expire or become invalid: (1) Shortcodes generated via aftv.news/dl have a limited lifespan — check if the shortcode is still valid on the website, (2) Some third-party shortcodes expire after a set number of uses or time period, (3) If using a shortcode from a tutorial or YouTube video, it may have been updated — check the original source for the latest code, (4) Generate a fresh shortcode from the official URL if needed, (5) As an alternative, enter the full APK URL directly instead of using a shortcode.
